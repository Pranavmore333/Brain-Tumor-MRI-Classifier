Project documentation

About this classifier

A Flask application for image-level brain MRI classification with a custom PyTorch CNN, Grad-CAM visualization, and a local SQLite case log.

01

Model

The four-block CNN classifies one 2D slice as glioma, meningioma, no tumor, or pituitary. Train it on your labeled image dataset before enabling inference.

02

Case review

Each result includes a Grad-CAM overlay and is saved locally. Add an optional review label to compare it with the model output.

03

Data handling

The app accepts PNG and JPG images. Case records are stored in SQLite, while the uploaded image and overlay are kept in the local uploads folder.

Local development

Train and run

  1. Install the packages: python -m pip install -r requirements.txt
  2. Put labeled images into dataset/Training and dataset/Testing.
  3. Each folder needs glioma, meningioma, notumor, and pituitary subfolders.
  4. Train: python train.py --epochs 10. Training uses a stratified 80/20 split of the Training folder.
  5. Evaluate on the held-out test set: python evaluate.py.
  6. Start the app: python app.py, then open http://127.0.0.1:5000.

The app handles 2D images only; DICOM and NIfTI volumes are not supported.

Research use only Model scores and Grad-CAM maps are not clinical evidence. Do not use this application to diagnose, triage, or treat patients. Use de-identified images and follow the dataset license.
