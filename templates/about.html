Project guide

Small enough to understand.
Complete enough to learn from.

SliceLab is an individual-student deep-learning project: one image classifier, one Flask app, one local database, and an explanation view.

01

The model

A custom four-block convolutional neural network built in PyTorch classifies a single 2D slice as glioma, meningioma, no tumor, or pituitary. It is trained from scratch on the dataset you supply.

02

The useful twist

Every result includes a Grad-CAM overlay and can be given an optional human review label. The local case log makes model/reviewer differences visible for learning and error analysis.

03

The stack

Flask serves the pages and JSON endpoints; SQLite stores case records; PyTorch handles training and inference; Pillow and OpenCV handle image input and Grad-CAM display.

Run it on your own dataset

Quick setup

  1. Install the packages: python -m pip install -r requirements.txt
  2. Put your permitted, labeled images into dataset/Training and dataset/Testing.
  3. Each folder needs glioma, meningioma, notumor, and pituitary subfolders.
  4. Train: python train.py --epochs 10. Training uses a stratified 80/20 split of the Training folder.
  5. Evaluate once on your held-out test set: python evaluate.py.
  6. Start the app: python app.py, then open http://127.0.0.1:5000.

The app accepts PNG/JPG 2D images only. It does not read DICOM or NIfTI volumes. No sample scans, fake scores, or pre-trained project checkpoint are bundled.

Important limitation This is an academic prototype, not a medical device or clinical decision-support tool. Predictions and Grad-CAM maps can be wrong or misleading; never use them to diagnose, triage, or treat anyone. Dataset quality, patient-level splits, external validation, privacy, and clinical/regulatory review are all outside this project.

Who it can help

A useful portfolio project, not a product claim

It is useful for students and instructors demonstrating image classification, explainability, API design, persistence, and human review. With appropriately licensed data and proper patient-level validation, it can support research into model errors or serve as an offline teaching tool.

For income, the realistic near-term value is employability: use the project to demonstrate skills for junior AI/ML or Python roles, or to offer tutoring and workshops. A clinical product would require substantial independent validation, privacy/security controls, specialist oversight, and regulatory approval before any sale.
